## Descripción del sistema
T&GSystem es un sistema de información enfocado a la automatización de procesos de negocio. El sistema agiliza los procesos de ventas del producto, fabricación de productos y compras de insumos, ademas de permitir la impresión de archivos, exportaciones a hojas de cálculo y reportes gráficos.

## Features
- Vistas de usuario distinguidas entre administrador y empleados
- Alto rendimiento para equipos con hardware limitado
- Impresión de documentos
- Exportación a excel
- Asistente de IA para evaluaciones de compras (beta)

## Stack técnico
- .NET Framework 4.7.2: Winforms, C#
- SQL Server 2022
